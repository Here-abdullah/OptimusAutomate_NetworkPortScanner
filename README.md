# 🌐 Network Port Scanner

A Python-based multithreaded Network Port Scanner developed as part of the **Optimus Automate Cyber Security Virtual Internship Program**.

## 📌 Features

- Scan IP Address or Hostname
- Scan Custom Port Range
- Multi-threaded Scanning
- TCP Connect Scan
- Common Service Detection
- Banner Grabbing
- Timeout Handling
- Export Results to CSV
- Colorized Terminal Output

## 🛠 Technologies Used

- Python
- Socket Programming
- Threading
- Queue
- CSV
- Colorama

## Installation

```bash
git clone https://github.com/Here-abdullah/OptimusAutomate_NetworkPortScanner.git

cd OptimusAutomate_NetworkPortScanner

pip install -r requirements.txt

python port_scanner.py
```

## ▶️ Usage

1. Enter the target IP address or hostname.
2. Enter the start port.
3. Enter the end port.
4. Wait for the scan to complete.
5. Optionally save the results as a CSV file.
